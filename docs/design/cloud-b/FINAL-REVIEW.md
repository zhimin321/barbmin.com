## 明确的验证限制

- **实际 200% 浏览器缩放未完成**：内置浏览器不提供缩放设置接口；快捷键尝试没有改变 innerWidth 或 devicePixelRatio。五档响应式量测不能替代实际 200% 缩放验收。
- **减少动态偏好未在浏览器中实际切换**：可用能力只有视口和可见性，没有媒体偏好模拟接口。减少动态规则已检查，实际切换不列为通过。
- **Windows 全局系统剪贴板未独立验证**：已验证浏览器工具所提供的剪贴板完整读回；未以另一 Windows 应用粘贴验证，不能把浏览器会话剪贴板等同于全局系统剪贴板。
- 无 JavaScript 阅读路径、复制失败退化逻辑属于代码检查，未通过关闭浏览器 JavaScript / 拒绝剪贴板权限实测。
- mailto 与 LinkedIn 的地址、标签和安全 rel 已核对；未发送邮件，未验证 LinkedIn 外站登录后的可用性。未进行真实手机、Safari/Firefox 或屏幕阅读器实测。
